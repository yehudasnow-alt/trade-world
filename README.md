# מטרופולין שוק ההון

עיר תלת-ממדית של מניות ה-S&P 500. כל רובע הוא סקטור, כל רחוב הוא תת-ענף וכל בניין הוא חברה. מאחורי העיר רצה מערכת שלמה: היא מושכת דיווחים מה-SEC, מחירים, יומן דוחות והתיק מ-IBKR. מכל דוח רבעוני היא בונה כרטיסיית דוח עם Claude, מאמתת כל מספר וכל ציטוט מול המקור, מחשבת ציון התכנסות, בודקת את התזות שלך ושולחת התראות לטלגרם.

המערכת בנויה להחזקות של חודש עד חצי שנה, ובעיקר לניתוח פונדמנטלי.

## מה יש בפנים

| חלק | מה הוא עושה |
|---|---|
| **העיר** (`web/`) | כל סקטור הוא רובע נפרד, וכל תת-ענף הוא שדרה עם בניינים משני צדיה. גובה כל בניין יחסי לשווי השוק שלו, כך שהחברה הגדולה היא המגדל הגבוה (אפשר לעבור לסולם דחוס). ארבעה מצבי תצוגה (שוק היום, ציד הזדמנויות, עונת דוחות, התיק שלי) משנים את הצבע. לכל חברה יש כרטיס עם ארבע לשוניות: סקירה, הדוח, מספרים, תזה ויומן. העיר כוללת גם תדריך בוקר, התראות, חיפוש (Ctrl K), מבט על דו-ממדי, מצב לילה ותצוגה לטלפון. |
| **SEC** (`metro/sources/sec.py`, `xbrl.py`, `sections.py`) | הזנת דיווחים כל 2 דקות ועובדות XBRL. רבעון רביעי מחושב מהשנה פחות 9 חודשים, ותזרים מחושב מהפרשי YTD. הדוח מפוצל לסעיפים, ומושווה ברמת המשפט לדוח הקודם (מה נוסף ומה נמחק בגורמי הסיכון ובניתוח ההנהלה). |
| **אירועים** (`metro/analytics/events.py`) | סיווג של כל פריט ב-8-K. דגלי וטו: 4.02 (דוחות לא אמינים), 3.01 (מחיקה מהמסחר), 1.03 (פשיטת רגל), going concern, דילול מעל 8%. בנוסף: עזיבת מנכ״ל או סמנכ״ל כספים, וקניות של בעלי עניין מעל 100 אלף דולר (Form 4, קוד P). |
| **כרטיסיות דוח** (`metro/ai/`) | שלוש שאלות: מה היה, מה יהיה ולאן הולכים. הכרטיסייה עוברת על רשימת כיסוי של 15 נושאים, ומתעדת שאלות ותשובות מהשיחה וספר הבטחות בין רבעונים. כל מספר נבדק מול XBRL או מול הטקסט, וכל ציטוט מול המקור. אצל אחזקות ומניות במעקב, Opus עובר על הכרטיסייה לפני שהיא נשמרת. יש תקרת הוצאה חודשית. |
| **ציון** (`metro/analytics/scoring.py`) | ארבעה רכיבים של 25 נקודות כל אחד: איכות (מול הסקטור), כיוון (האצה, תחזית, הפתעה), תמחור (מול ההיסטוריה של החברה עצמה ומול הרחוב) ותזמון. דגלי וטו מאפסים. "אלומה" נדלקת על חברה עם ציון גבוה, ירידה מהשיא ותמחור נמוך. |
| **תזה** (`metro/analytics/thesis.py`) | מדדים שחייבים להחזיק ותנאי ביטול. כל דוח ואירוע בודק אותם, והסטטוס מתעדכן ל"תקפה", "במעקב" או "נשברה". |
| **התראות ותדריך** (`metro/alerts.py`, `brief.py`) | שלוש רמות: דחוף, חשוב ולסיכום. שעות שקט מוגדרות (דחוף עובר גם בהן). תדריך בוקר בטלגרם. |
| **שרת ומשימות** (`metro/api.py`, `jobs.py`) | שרת FastAPI ותזמון לפי לוח המסחר של NYSE, כולל חגים וימים מקוצרים. |

## התחלה מהירה: הדגמה בשלוש פקודות

צריך Python 3.11 ומעלה.

```bash
pip install -e .
metro demo        # כ-30 שניות: רשימת החברות האמיתית, מחירים ודוחות מומצאים
metro run         # פתח http://127.0.0.1:8000
```

במצב הדגמה רשימת החברות, הסקטורים ותתי-הענפים אמיתיים. כל השאר מומצא: מחירים, דוחות, ציונים והתיק. הממשק מסמן את זה בתגית "נתוני הדגמה". הנתונים עוברים דרך אותו קוד ציונים, תזות והתראות של המצב החי, כך שההדגמה מריצה את המערכת האמיתית.

## מעבר לנתונים חיים

```bash
cp .env.example .env     # ממלאים מפתחות (פירוט למטה). כל מפתח שחסר פשוט משאיר את המקור כבוי.
metro init               # מסד נתונים חדש במצב חי
metro backfill           # משיכה ראשונית: SEC, מחירים, יומן דוחות, תיק. כשעה ל-500 חברות.
metro gold               # כרטיסיות ל-AAPL, NVDA, JPM, PLD, MSFT: בדיקת איכות לפני שמפעילים על כולם
metro run
```

`metro status` מראה מה מחובר ומתי כל מקור התעדכן לאחרונה. אותו מידע מופיע גם בממשק, בנקודה שליד כפתור הנושא.

### חשבונות ומפתחות

| מקור | עלות | בשביל מה | משתנים ב-`.env` |
|---|---|---|---|
| SEC EDGAR | חינם | דיווחים, XBRL, 8-K, Form 4 | `SEC_USER_AGENT` |
| Anthropic | לפי שימוש, עם תקרה | כרטיסיות דוח | `ANTHROPIC_API_KEY` |
| Alpaca | חינם | מחירים (מושהים ב-15 דקות) ונרות יומיים | `ALPACA_KEY_ID`, `ALPACA_SECRET_KEY` |
| Finnhub | חינם | יומן דוחות והפתעות | `FINNHUB_API_KEY` |
| IBKR Flex | חינם | התיק והעסקאות, פעם ביום | `IBKR_FLEX_TOKEN`, `IBKR_FLEX_QUERY_ID` |
| IB Gateway | חינם (נתוני שוק לפי המינוי שלך) | מחירים חיים לתיק ולרשימת המעקב | `IBKR_LIVE=true` |
| Telegram | חינם | התראות ותדריך בוקר | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |
| תמלולי שיחות | חינם (קבצים) או FMP בתשלום | שאלות ותשובות מהשיחה | `FMP_API_KEY` או תיקייה |

**SEC.** אין הרשמה. ה-SEC מבקש מכל תוכנה שפונה אליו להזדהות בשם ובכתובת מייל. כותבים את שלכם:
`SEC_USER_AGENT="Your Name you@example.com"`. המערכת שומרת על 8 בקשות לשנייה (התקרה של ה-SEC היא 10) ושומרת עותק מקומי של כל מסמך.

**Anthropic.** יוצרים מפתח ב-console.anthropic.com תחת API Keys. ברירת המחדל:
- Haiku לכרטיסייה קצרה של כל חברה.
- Sonnet לכרטיסייה מלאה של אחזקות ומניות במעקב.
- Opus לביקורת עליהן.

`AI_DEEP_SCOPE=all` נותן כרטיסייה מלאה לכל החברות, וזה יקר יותר. `AI_MONTHLY_BUDGET_USD` עוצר את התור כשמגיעים לתקרה. כדי לראות גודל ועלות משוערת בלי לשלוח, הריצו `metro card NVDA --dry-run`.

**Alpaca.** פותחים חשבון ב-alpaca.markets. חשבון Paper מספיק, ומפתחות ה-API נמצאים בדשבורד שלו. התוכנית החינמית נותנת את כל השוק בהשהיה של 15 דקות (`ALPACA_FEED=delayed_sip`). אם החשבון לא מקבל את הזרם הזה, המערכת עוברת לבד ל-IEX.

**Finnhub.** מפתח חינמי ב-finnhub.io. המערכת שומרת על פחות מ-60 בקשות לדקה.

**IBKR Flex (התיק).** בפורטל של IBKR: Performance & Reports ← Flex Queries.
1. יוצרים Activity Flex Query עם הסעיפים **Open Positions** (רמת פירוט Summary) ו-**Trades**, תקופה Last Business Day, פורמט XML. מספר השאילתה הוא `IBKR_FLEX_QUERY_ID`.
2. באותו עמוד, ב-Flex Web Service Configuration, מפעילים את השירות ומפיקים Token. זה `IBKR_FLEX_TOKEN`.

ה-Flex מאפשר רק קריאה ולא דורש תוכנה פתוחה. המערכת מושכת אותו כל בוקר ב-06:40 שעון ניו יורק. למשיכה ידנית: `metro flex`.

**IB Gateway (מחירים חיים, לא חובה).** מתקינים IB Gateway ונכנסים לחשבון.
1. ב-Configure ← Settings ← API ← Settings מסמנים Enable ActiveX and Socket Clients.
2. משאירים מסומן את **Read-Only API**.
3. פורט 4001 לחשבון אמיתי, 4002 ל-Paper. מוסיפים את 127.0.0.1 ל-Trusted IPs.

המערכת מתחברת עם `readonly=True` ולא יכולה לשלוח פקודות. היא עוקבת אחרי עד 90 סימולים: קודם התיק, אחר כך רשימת המעקב. בלי מינוי לנתוני שוק, IB מחזירה מחירים מושהים.

**Telegram.**
1. ב-@BotFather שולחים `/newbot`, והטוקן שמתקבל הוא `TELEGRAM_BOT_TOKEN`.
2. שולחים הודעה כלשהי לבוט החדש.
3. פותחים `https://api.telegram.org/bot<TOKEN>/getUpdates`. המספר שב-`chat.id` הוא `TELEGRAM_CHAT_ID`.

כדי לבדוק: `metro brief --send`.

**תמלולי שיחות.** שמים קובץ טקסט בנתיב `data/transcripts/<TICKER>/<YYYY>Q<n>.txt`, לפי השנה והרבעון **הפיסקליים** של החברה. לדוגמה, השיחה של אפל על הרבעון הראשון של שנת הכספים 2026 נשמרת ב-`data/transcripts/AAPL/2026Q1.txt`. את הטקסט אפשר להעתיק מה-PDF שבאתר קשרי המשקיעים. עם `FMP_API_KEY` המערכת מורידה את התמלול לבד. בלי תמלול, הכרטיסייה נבנית מההודעה לעיתונות ומה-10-Q, והחלק של השאלות והתשובות מסומן כחסר.

## Docker

```bash
cp .env.example .env    # ממלאים מפתחות
docker compose up -d --build
docker compose exec metropolin metro backfill
```

הנתונים נשמרים בתיקייה `data/` שליד הקובץ. אם IB Gateway רץ על המחשב עצמו, הקונטיינר מגיע אליו דרך `host.docker.internal`. ב-Gateway צריך להוסיף את כתובת הקונטיינר ל-Trusted IPs.

## תצוגה ב-Vercel

התיקייה `site/` מכילה את ההדגמה כדף סטטי אחד: Three.js נטען מ-CDN והנתונים מוטמעים בדף. הקובץ `vercel.json` מגדיר את Vercel להגיש את התיקייה הזו בלי התקנה ובלי בנייה.

1. ב-Vercel בוחרים Add New ← Project ומייבאים את הריפו.
2. לא משנים שום הגדרה. ההגדרות כבר נמצאות ב-`vercel.json`.
3. כל דחיפה ל-`main` מעדכנת את התצוגה.

ב-Vercel רצה רק ההדגמה. המערכת החיה צריכה שרת שרץ כל הזמן, מסד נתונים ותזמון, ולכן היא רצה על המחשב שלך או על שרת קטן (ראו Docker). שינויים שתעשה בדף ההדגמה, כמו תזה, רשימת מעקב או יומן, נשמרים רק בדפדפן שלך.

לרענון ההדגמה אחרי שינוי בממשק:

```bash
metro demo && metro web --demo    # מעדכן את site/index.html
git add site && git commit -m "Refresh demo" && git push
```

## גישה מהטלפון

ברירת המחדל היא שהשרת פתוח רק במחשב עצמו (`127.0.0.1`). כדי לפתוח אותו לטלפון:
1. קובעים `ACCESS_TOKEN` ארוך ואקראי ב-`.env`.
2. מגדירים `HOST=0.0.0.0`.
3. מתחברים דרך רשת פרטית כמו Tailscale או WireGuard, ולא חושפים את הפורט לאינטרנט.
4. פותחים פעם אחת `http://<כתובת>:8000/?token=<הקוד>`. הדפדפן זוכר את הקוד חצי שנה.

## מבנה הקוד

```
metro/
  sources/     sec, xbrl, sections, alpaca, finnhub, ibkr, transcripts
  analytics/   technicals, valuation, events, scoring, thesis
  ai/          schema, prompts, engine, runner, verify
  pipeline.py  מחבר את המקורות למסד הנתונים ולציונים
  api.py       ה-API והגשת הממשק
  jobs.py      התזמון
  clock.py     לוח המסחר של NYSE
  demo.py      נתוני ההדגמה
  webbuild.py  בניית הממשק
web/src/index.src.html   הממשק (קובץ אחד: Three.js, RTL)
web/vendor/              Three.js 0.169 מקומי, כדי שהשרת לא יהיה תלוי ב-CDN
site/                    ההדגמה כדף סטטי (Vercel)
data/                    רשימת החברות, נושאים (themes.json), שרשרת אספקה (relations.json), מסד הנתונים
tests/                   בדיקות על צורות תשובה מוקלטות, כולל זרימה מלאה מדיווח ועד כרטיסייה מאומתת
```

את `data/relations.json` (ספקים ולקוחות) ואת `data/themes.json` (נושאים כמו תשתיות AI או GLP-1) עורכים ביד. השרת קורא אותם מחדש כשהם משתנים. בכרטיס החברה, הקשרים מצוירים כמסלולים על הכבישים.

## בדיקות

```bash
pip install -e ".[dev]"
pytest -q
```

הבדיקות רצות גם ב-GitHub Actions על כל דחיפה (`.github/workflows/tests.yml`).

הבדיקות לא פונות לרשת. כל לקוח מקבל `httpx` transport מוקלט. יש גם בדיקה של כל הזרימה החיה: דיווח 10-K ו-8-K, עובדות XBRL, פיצול לסעיפים, תור ל-Claude (מזויף), כרטיסייה מאומתת וביקורת.

## מגבלות שכדאי לדעת

- **הבדיקה ההיסטורית משתמשת ברשימת ה-S&P 500 של היום.** חברות שיצאו מהמדד חסרות בה, ולכן התוצאות אופטימיות. הפקודה מציינת את זה בפלט.
- **Alpaca בחינם מושהה ב-15 דקות.** למחירים חיים צריך IB Gateway עם מינוי לנתוני שוק.
- **כרטיסייה טובה כמו המקורות שלה.** בלי תמלול השיחה אין שאלות ותשובות. מספר שלא נמצא במקור מסומן ב-"!" ולא מוצג כעובדה.
- **הציון הוא כלי סינון ולא המלצה.** הוא מסמן איפה כדאי להסתכל. ההחלטה, וגודל הפוזיציה במחשבון העסקה, נשארים שלך.
